# Clayloom

A shared table, not a dashboard.

Clayloom uses cream and espresso surfaces, terracotta accents and rounded navigation. Soft message blocks give each contribution a clear contour. Replies keep their native single-line preview; generous input and picker surfaces repeat the softer geometry.

## Geometry

20px panels, asymmetric composer corners, pill navigation, soft grouped settings and breathable reactions.

## Typography and motion

Discord's own font stack and user font size remain intact. Hierarchy comes from grouping, spacing and weight; code alone uses the native monospace. Native icons remain identifiable and user roles retain their colors. Background changes last 180ms; no theme animation loops. Reduced motion disables authored transitions.

## Decisions

No photographs, external fonts or icon libraries. An original geometric logo is documentation-only. No decorative dashboard labels, invented telemetry or cosmetic controls. Text blocks have soft corners and a reading measure of 76ch. The native negative text indent is reset only on these blocks; reply previews are excluded.
